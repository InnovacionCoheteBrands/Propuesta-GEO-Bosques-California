# Checklist: SEO Técnico Básico

- [ ] **Indexabilidad:** La página no tiene etiquetas `noindex`.
- [ ] **Canónical:** La URL canónica está correctamente definida.
- [ ] **Mobile-Friendly:** La página se visualiza correctamente en dispositivos móviles.
- [ ] **Velocidad:** Imágenes comprimidas y carga optimizada (LCP < 2.5s).
- [ ] **HTTPS:** El certificado SSL está activo.
- [ ] **Sitemap:** La URL está incluida en el sitemap.xml.

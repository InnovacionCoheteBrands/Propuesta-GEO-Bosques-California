# SEO & GEO Framework: El Nuevo Estándar

## 1. SEO vs. GEO
- **SEO (Search Engine Optimization):** Enfoque en rankings, CTR y experiencia de usuario en navegadores. Se basa en algoritmos de relevancia y autoridad (Backlinks, Core Web Vitals).
- **GEO (Generative Engine Optimization):** Enfoque en la probabilidad de ser incluido en la respuesta sintetizada de una IA. Se basa en la claridad semántica, cobertura de entidades y citabilidad.

## 2. El Modelo de Trabajo
Todo entregable de este skill sigue el ciclo:
**Investigar** (Datos reales) -> **Planear** (Estrategia semántica) -> **Generar** (Contenido optimizado).

## 3. Principios de Visibilidad
- **Relevancia:** Alineación exacta con la intención de búsqueda (Search Intent).
- **Autoridad (E-E-A-T):** Demostrar Experiencia, Pericia, Autoridad y Confianza.
- **Estructura:** Uso jerárquico de headings y datos estructurados.
- **Citabilidad:** Frases claras y factuales que una IA pueda extraer como "fuente de verdad".

## 4. Entidades y Tópicos
No optimizamos para "palabras", optimizamos para "conceptos". Una página sobre "Casas en Venta" debe cubrir entidades relacionadas como "crédito hipotecario", "plusvalía", "amenidades" y "ubicación geográfica".
